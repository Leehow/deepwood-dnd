# 2026-01-21 图片存储优化

## 概述

优化服务器空间占用，所有图片上传转为 WebP 格式并存储到阿里云 OSS。

## 修改的文件

### 1. `backend/app/api/routes/characters.py`
- 修改 `update_character_avatar` 端点
- 用户上传头像现在会转为 WebP 并上传到 OSS
- 数据库只存储 OSS URL（小图 `avatar`，大图 `avatar_large`）

### 2. `backend/app/api/routes/character_crud.py`
- 同上，修改 `update_character_avatar` 端点

### 3. `backend/app/utils/image_storage.py`
- 本地后备存储也改为 WebP 格式
- 移除 `force_png` 参数
- 使用与 OSS 相同的 WebP 质量设置 (quality=85)

### 4. `backend/app/services/avatar_service.py`
- 移除调用中的 `force_png=True` 参数

## 存储路径

| 类型 | OSS 路径 |
|------|---------|
| 头像 | `dnd-avatars/{entity_type}/{YYYY/MM/DD}/{prefix}_{hash}_{size}.webp` |
| 地图 | `dnd-maps/{YYYY/MM/DD}/c{campaign_id}_{map_id}_{hash}.webp` |
| 模块图片 | `dnd-modules/{module_id}/images/{YYYY/MM/DD}/{image_id}_{hash}.webp` |

## 注意事项

- 需要配置 OSS 环境变量才能正常工作
- PDF 文件处理完成后会自动删除，不占用服务器空间

# 2026-01-21 Bug修复与安全加固

## React Hydration 错误修复

修复生产环境控制台报错 (#418, #425, #423)

**问题原因:**
- 登录页内联 `<style>` 标签在 SSR 时 HTML 编码 `'` 为 `&#x27;`，CSR 时为原始 `'`
- MusicPlayer 组件 SSR/CSR 渲染不一致

**修复方案:**
1. 将登录页内联样式提取到外部 CSS 文件 `app/styles/login.css`
2. MusicPlayer 添加 `mounted` 状态确保 SSR/CSR 一致渲染

**修改文件:**
- `frontend/app/routes/login.tsx` - 移除内联样式，改为 import CSS
- `frontend/app/styles/login.css` - 新建，包含所有登录页样式
- `frontend/app/components/MusicPlayer.tsx` - 添加 mounted 状态模式

## 背景音乐停止播放

**问题:** 进入战役后背景音乐继续播放

**修复:** MusicPlayer 组件卸载时调用 `cleanup()` 停止音乐

**修改文件:**
- `frontend/app/components/MusicPlayer.tsx` - useEffect 返回 cleanup 函数

## "返回大厅"按钮修复

**问题:** 点击返回大厅跳转到 `https://www.deepwood.cn/` 而非 `/dnd/`

**修复:** 使用 `import.meta.env.BASE_URL` 动态获取基础路径

**修改文件:**
- `frontend/app/routes/campaign.$id.dm.tsx` - 修复 onExit 回调
- `frontend/app/routes/campaign.$id.player.tsx` - 修复 onExit 回调

## API 安全加固

**问题:** `/api/ai-settings` 和 `/api/ai-settings/usage-configs` GET 端点无权限检查，任何人可读取 API 密钥

**修复:** 所有 AI 设置相关端点添加 admin 权限检查

**修改文件:**
- `backend/app/api/routes/ai_settings.py`
  - `GET /ai-settings` - 添加 require_admin
  - `GET /usage-configs` - 添加 require_admin
  - `POST /fetch-models` - 修复缺失的 db 参数
