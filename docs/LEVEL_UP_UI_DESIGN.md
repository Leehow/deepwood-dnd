# D&D 5E 升级系统UI设计文档

## 概述

改进了角色升级系统的UI设计，使其更精细、更符合D&D 5E规则，提供了职业特性选择、法术位展示、子职业选择等功能。

## 主要改进

### 1. 分步升级流程

原设计只是简单选择要升级的职业，新设计分为两步：

**第一步：选择职业**
- 显示现有职业及其等级变化（如 战士 3 → 4）
- 预览该等级将获得的特性
- 对于施法职业，显示法术位变化提示
- 支持兼职新职业

**第二步：选择特性**
- 展示该等级获得的所有特性
- 对于需要选择的特性，提供交互式选择界面

### 2. 职业特性展示

每个等级的特性根据类型不同，有不同的展示和交互方式：

#### 特性类型

**战斗风格（Fighting Style）**
- 类型：choice
- 展示所有可选风格及其描述
- 如：箭术（远程武器攻击+2）、防御（AC+1）等

**子职业选择（Subclass）**
- 类型：subclass
- 战士3级选择武术范型
- 法师2级选择奥术传统
- 游荡者3级选择游荡者范型

**属性提升或专长（ASI/Feat）**
- 类型：asi_or_feat
- 可选择+2到一项属性，或+1到两项属性，或选择一个专长

**专精技能（Expertise）**
- 类型：expertise
- 游荡者特有，选择技能获得双倍熟练加值

**常规特性（Feature）**
- 类型：feature
- 自动获得，无需选择
- 如：额外攻击、动作如潮等

### 3. 法术位展示

对于施法职业（法师、牧师等），展示法术位变化：

```
环阶    1  2  3  4  5
当前    4  3  -  -  -
新      4  3  2  -  -  (新增的以绿色高亮)
```

### 4. 数据结构设计

#### classes.json 结构

```json
{
  "fighter": {
    "name": "战士",
    "nameEn": "Fighter",
    "hitDice": "1d10",
    "primaryAbility": ["strength", "dexterity"],
    "savingThrows": ["strength", "constitution"],
    "levelProgression": {
      "1": {
        "proficiencyBonus": 2,
        "features": [
          {
            "name": "战斗风格",
            "nameEn": "Fighting Style",
            "type": "choice",
            "choices": [...]
          }
        ]
      }
    }
  }
}
```

#### 特性数据结构

```typescript
interface Feature {
  name: string;          // 中文名
  nameEn: string;        // 英文名
  type: 'choice' | 'subclass' | 'asi_or_feat' | 'expertise' | 'feature';
  description?: string;  // 描述
  choices?: Choice[];    // 可选项
  uses?: number;        // 使用次数
  damage?: string;      // 伤害（如偷袭骰）
  count?: number;       // 数量（如专精技能数）
}
```

### 5. UI组件设计

#### EnhancedLevelUpModal 组件

主要功能：
- 步骤指示器显示当前进度
- 职业选择卡片，带特性预览
- 特性选择界面，根据类型动态渲染
- 法术位变化表格
- 确认和取消按钮

视觉设计：
- 使用紫色作为主色调（升级）
- 绿色表示新增/兼职
- 黄色表示子职业选择
- 蓝色表示法术相关

### 6. 各职业升级特点

#### 战士（Fighter）
- 1级：选择战斗风格
- 2级：获得动作如潮
- 3级：选择武术范型（子职业）
- 4级：属性提升或专长
- 5级：额外攻击

#### 法师（Wizard）
- 1级：施法能力，奥术回复
- 2级：选择奥术传统（子职业）
- 3级：法术位提升
- 4级：属性提升或专长，戏法数量增加
- 5级：3环法术位

#### 游荡者（Rogue）
- 1级：专精技能选择，偷袭
- 2级：巧妙动作
- 3级：选择游荡者范型（子职业），偷袭提升到2d6
- 4级：属性提升或专长
- 5级：直觉闪避，偷袭提升到3d6

#### 牧师（Cleric）
- 1级：选择神圣领域（子职业），施法
- 2级：引导神力
- 3级：法术位提升
- 4级：属性提升或专长，戏法数量增加
- 5级：摧毁亡灵

### 7. 后续优化建议

1. **专长系统**：实现完整的专长列表和选择界面
2. **属性提升界面**：可视化属性点分配
3. **法术选择**：为施法职业添加法术选择界面
4. **技能专精**：实现技能列表和专精选择
5. **子职业特性**：根据所选子职业显示对应特性
6. **生命骰**：显示生命值增加（骰子或平均值）
7. **多职业规则**：完善多职业的熟练、法术位计算
8. **特性依赖**：某些特性可能依赖于之前的选择

### 8. 技术实现要点

- 使用 React Hooks 管理状态
- 分步骤界面使用状态机模式
- 特性选择存储在 featureChoices 对象中
- 支持取消和返回上一步
- 数据从 classes.json 读取（可扩展到数据库）

## 总结

新的升级UI设计更贴近D&D 5E的实际规则，提供了更丰富的交互和视觉反馈，让玩家在升级时能够清楚地了解自己获得的新能力，并做出符合角色定位的选择。这种设计既适合新手玩家（通过描述了解特性），也适合老玩家（快速选择熟悉的选项）。
