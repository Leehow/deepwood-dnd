### 5. 添加数据库预加载优化 ✓

**目标：** 避免N+1查询问题，提升数据库查询效率

**实施内容：**
- ✅ 在 `campaigns.py` 中导入 `selectinload`
- ✅ 优化 `get_campaign` 端点：
  ```python
  select(Campaign)
    .where(Campaign.id == campaign_id)
    .options(selectinload(Campaign.members))  # 预加载关联数据
  ```

**收益：**
- ✓ 减少数据库查询次数（从1+N次减少到2次）
- ✓ 提升API响应速度
- ✓ 降低数据库负载
