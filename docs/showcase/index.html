AI-assisted virtual tabletop / AI 辅助虚拟桌面

Deepwood DND

A full-stack D&D-style campaign platform for real-time tactical play, automated character math, asset management, dice adjudication, module reading, and AI-assisted DM preparation.

一个面向 D&D 风格战役的全栈平台：实时战术桌面、角色自动计算、资产管理、 骰子裁定、AI 读规则/读模组、AI 备团和实时生成战役资产。

One workspace for the whole table / 一张桌子，跑完整场团

Deepwood DND brings the DM, players, tactical state, rules context, dice, maps, NPCs, monsters, treasure, and AI-generated prep into the same campaign workspace.

Realtime combat / 实时战斗Initiative, token state, actions, reactions, range, AC, HP, and turn flow.
Character automation / 角色自动计算Race/class flow, derived stats, resources, equipment, and sheet data.
Dice automation / 骰子自动计算Visible d20 math, DC checks, attack rolls, damage, and adjudication.
AI module prep / AI 备团Read rules/modules, summarize prep, suggest encounters, and create assets.
Asset management / 资产管理Inventory, currency, item icons, portraits, chests, loot, NPCs, and monsters.
Map generation / 地图生成Upload maps, align scale, transform, or generate new scenes with AI.

Character creation / 创建角色自动计算

Step-by-step character builder for race, class, features, attributes, equipment, and final review.

  • Ability bonuses and derived sheet values are calculated where possible.
  • Players get a usable character sheet without hand-wiring formulas.

AI reads rules and modules / AI 读规则、读模组与备团

Turn module notes into DM prep cards, NPCs, encounters, routes, rumors, and map prompts.

  • Ask about module content and generate concrete campaign assets.
  • Prepare balanced fights or variants for different party sizes.
