Deepwood DND

A full-stack D&D-style campaign platform for real-time tactical play, automated character math, asset management, dice adjudication, module reading, and AI-assisted DM preparation.

一个面向 D&D 风格战役的全栈平台：实时战术桌面、角色自动计算、资产管理、 骰子裁定、AI 读规则/读模组、AI 备团和实时生成战役资产。
